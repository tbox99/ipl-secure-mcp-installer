# Contributing

Issues and pull requests are welcome. Describe expected behavior and provide reproducible steps.

- Never submit API keys, Tunnel IDs, SSH keys, personal hostnames, private paths, or raw logs containing secrets.
- Prefer small, focused changes with Bash syntax checks (`bash -n install.sh`).
- Clearly distinguish source-level testing from real end-to-end tunnel testing.
- Changes to ADMIN security and filesystem permissions require careful justification and review.
- The upstream MCP server and OpenAI Tunnel Client are external projects; report their own bugs to their respective maintainers where appropriate.
